# Liver Disease Prediction

A collaborative academic data mining project using machine learning to predict liver disease based on patient medical data.

## Project Overview
The project used the Indian Liver Patient Dataset, containing 583 patient records, to explore patterns associated with liver disease.

## Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Methodology
- Exploratory data analysis
- Data preprocessing and outlier analysis
- Logistic Regression with hyperparameter tuning
- Decision Tree and Random Forest
- Model evaluation and comparison

## Results
The Logistic Regression model achieved approximately 69% accuracy and an AUC score of 0.75 on the test set.

## Project Type
Collaborative academic project.
